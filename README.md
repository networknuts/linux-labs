## Lab Safety

- Perform privileged exercises only on disposable classroom systems.
- Confirm hostnames, device names, mount points, and network interfaces before making changes.
- Preserve remote access while changing networking, firewall, or SSH settings.
- Validate persistent storage configuration before rebooting.
- Capture verification output after completing each exercise.
